# About

This blog is built with [Eleventy](https://www.11ty.dev/), edited through
[Sveltia CMS](https://github.com/sveltia/sveltia-cms), searched with
[Pagefind](https://pagefind.app/), and deployed to GitHub Pages. Every deploy
runs an accessibility scan, published on the [Accessibility](/accessibility/)
page.

<div class="colophon">
<p>
Design and colors drawn from <cite><a href="https://dpul.princeton.edu/catalog/dc9019sd49x">The Infant's Library</a></cite>,
a miniature bookcase of tiny volumes held by Princeton University Library —
each post here is a little book of its own, pulled off the shelf one at a time.
